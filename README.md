## 💎 Loyiha Konsepsiyasi (Product Vision)

Ko‘plab kichik va o‘rta biznes egalari veb-sayt buyurtma qilishda bir xil muammolarga duch kelishadi:
* Qaysi turdagi veb-sayt (*Landing page, Business site, Katalog yoki Veb-ilova*) kerakligini aniq bilishmaydi;
* Dasturchi va dizaynerga o‘z texnik topshirig‘ini (TZ) tushuntirishda qiynalishadi;
* Bir xil, zerikarli va shablonli saytlardan charchashgan;
* Soxta sharhlar va to‘qima statistikalar bilan to‘lgan agentliklardan hafsalasi pir bo‘lgan.

**NOVA®** aynan shu muammolarni hal qilish uchun yaratilgan:
1. **Shaffof tahlil vositasi** orqali optimal formatni tanlab beradi (**Solution Finder**);
2. 4 bosqichda aniq texnik ariza tuzishga yordam beradi (**Project Brief**);
3. Har bir formatning haqiqiy muammo va yechimini ko‘rsatuvchi **chuqurlashtirilgan keyslar**ni taqdim etadi (**Case Studies**);
4. Studiya rahbariga kelib tushgan lidlarni boshqarish uchun maxsus **Lead CMS Admin Panel** taqdim etadi.

## 🎨 Vizual Yo‘nalish va Dizayn Tizimi (Design System)

NOVA® oddiy korporativ shablon emas — u xalqaro Awwwards va tahririy san'at jurnallari estetikasida qurilgan:

* **Asosiy Palitra:**
  * `Studio Black` (`#0A0F1D`) — chuqur, qat'iy va mustaqil studiya foni;
  * `Cobalt Blue` (`#1D4ED8`) — intellektual muhandislik va ishonchlilik ramzi;
  * `Warm Orange` (`#EA580C`) — qizg‘in ijodkorlik va aksent nurlari;
  * `Studio Light` (`#F8FAFC`) — matnlar uchun nafis kontrast va bo‘shliqlar (whitespace).
* **Tipografika Juftligi:**
  * Sarlavhalar: **Space Grotesk** — geometrik, qat'iy va zamonaviy tahririy shrift;
  * Matnlar: **Plus Jakarta Sans** — o‘qish oson bo‘lgan ergonomik shrift.
* **Taktil Elementlar:** Analog plyonka donadorligi (*film grain texture*), nozik porlovchi gradientlar (*ambient glow*), kartalarning 3D mayin ko‘tarilishi (*motion-elevate*) va tahririy cheksiz lenta (*infinite marquee ribbon*).

### 1. Formatlar Taqqoslash Matritsasi (Desktop & Mobile Dual-View)
To‘rtta asosiy format:
- **Landing Page:** Bitta xizmat yoki mahsulotga mijoz to‘plash;
- **Business Website:** Kompaniya nufuzi va xizmatlar taqdimoti;
- **Product Catalog:** Mahsulotlar filtri, toifalari va buyurtma shakli;
- **Custom Web App:** Shaxsiy kabinet, avtomatlashtirish va tahlil.
> *Mobil qurilmalarda jadval siqilib ketmasligi uchun "Kartalar" va "Jadval" rejimlari o‘rtasida silliq almashtirish imkoniyati yaratilgan.*

### 2. Chuqurlashtirilgan Keyslar (Deep-Dive Case Studies)
Har bir loyiha real fotorealistik muqova, biznes to‘siqlari, strategiya, nima uchun boshqa formatlar rad etilgani va texnik vositalar bilan yoritilgan:
- **Nordic Atelier** — Mebel va arxitektura brendining tahririy platformasi;
- **Zenith Global Cargo** — Sanoat logistikasi uchun yuqori konversiyali lending;
- **Kura Roastery** — Qahva donalari va ta'm profillari interaktiv katalogi;
- **Strata Ops** — Retail tarmoqlari ombor balansi boshqaruv tizimi (Custom App).

### 3. Interaktiv Solution Finder
Foydalanuvchiga 5 ta aniq savol beradi: soha, muammo, maqsad, byudjet va talab qilinadigan funksiyalar. Sun'iy illyuziyalarsiz, shaffof qoidalar asosida eng to‘g‘ri formatni tanlab beradi va javoblarni saqlab qoladi.

### 4. Ko‘p Bosqichli Project Brief & Konfetti
Mijoz o‘z aloqa ma'lumotlarini, sahifalar ro‘yxatini, byudjet va muddatini kiritadi. Solution Finder natijalari avtomatik joylashtiriladi. Yuborilganda bayramona konfetti effekti otiladi va tayyor xulosani Telegram yoki emailga nusxalab olish imkoniyati beriladi.

## 🔐 Yashirin Admin Panel (Demo Access)

Sayt estetikasi va haqiqiy studiya nufuzini saqlab qolish uchun boshqaruv paneli **ommaviy tashrif buyuruvchilarga ko‘rinmaydi**.

Portfolio ko‘ruvchilar, mijozlar va rekruterlar tizimni to‘liq sinab ko‘rishlari uchun:

| Parametr | Qiymat |
| :--- | :--- |
| **Kirish Manzili** | Sayt havolasi oxiriga `/#admin` qo‘shing *(masalan: `https://your-site.vercel.app/#admin`)* |
| **Mahalliy Manzil** | `http://localhost:5173/#admin` |
| **Kirish Paroli** | `nova2026` |

**Admin Panel Imkoniyatlari:**
* 📊 **KPI Kartalar:** Jami arizalar soni, yangi lidlar, jarayondagi loyihalar va umumiy byudjet;
* 🔍 **Kuchli Qidiruv & Filtrlar:** Ism, kompaniya, email, telefon yoki status bo‘yicha tezkor saralash;
* 📑 **Brief Inspektori:** Mijoz kontaktlariga 1 bosishda o‘tish (Telegram, Email), texnik topshiriq tahlili;
* 📝 **Ichki Studiya Qaydlari (Admin Notes):** Jamoa uchun maxfiy izohlar yozish va saqlash;
* 🔄 **Status Boshqaruvi:** *Yangi* → *Jarayonda* → *Taklif yuborildi* → *Qabul qilindi*;
* 💾 **Bir Zumda Eksport:** Barcha lidlarni `CSV` (Excel) yoki `JSON` qilib yuklab olish.

## 🚀 Mahalliy Ishga Tushirish (Quick Start)

### 1. Repozitoriyni kompyuterga yuklab oling:
```bash
git clone https://github.com/sardorergashev09uzb-commits/Nova.git
cd Nova
```

### 2. Bog‘liqliklarni o‘rnating:
```bash
npm install
```

### 3. Dasturchi serverini yoqing:
```bash
npm run dev
```

Sayt brauzeringizda ochiladi: **`http://localhost:5173/`**

### 4. Ishlab chiqarish yig‘masini sinab ko‘rish:
```bash
npm run build
```
Yig‘ilgan statik fayllar `dist/` papkasida hosil bo‘ladi (Typecheck va CSS siqilishidan toza o‘tadi).
